# Data for the project
This repository holds all the data used in the project.
+ The pdf file contains all the data combined and it is taken from the supplementary material of the [paper](https://peerj.com/articles/3066/).
+ All the other files are used to divide the data for each garden center and make it computer-readable. They are a csv files with the same structure as the original file.
The data necessary to run the notebook is already present in it.
